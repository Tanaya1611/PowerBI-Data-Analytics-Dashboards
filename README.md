# Power BI Data Analytics Dashboards

A collection of interactive Power BI dashboards created to demonstrate practical skills in data analysis, data visualization, DAX, Power Query, Excel, SQL, and Business Intelligence.

## 📊 Dashboards

### 1. Classic Model Dashboard

Business sales analysis using the Classic Models dataset.

**Key Areas:**

* Sales Performance
* Orders & Customers
* Product Analysis
* Revenue & Profit Insights
* Interactive Filters

**Tools:** Power BI, DAX, Power Query

### 2. Healthcare Analytics Dashboard

Interactive healthcare dashboard for analyzing patients, doctors, appointments, admissions, billing, pharmacy, and laboratory data.

**Key Areas:**

* Patient Analysis
* Doctor Analysis
* Appointment Trends
* Admission Analysis
* Billing Analysis
* Pharmacy & Laboratory Insights

**Tools:** Power BI, DAX, Power Query, Excel

### 3. HR Analytics Dashboard

HR analytics dashboard designed to analyze recruitment and workforce-related data.

**Key Areas:**

* Recruitment Analysis
* Job Role Analysis
* Department Analysis
* Interview Score Analysis
* Salary Analysis
* Application Status

**Tools:** Power BI, DAX, Power Query

### 4. Sales Dashboard

Business sales dashboard designed to monitor sales performance and identify important business trends.

**Key Areas:**

* Sales Performance
* Revenue Analysis
* Product Analysis
* Customer Insights
* Sales Trends

**Tools:** Power BI, DAX, Power Query
